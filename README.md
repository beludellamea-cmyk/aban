# ABANICADOS

Catálogo estático listo para GitHub Pages.

- `index.html` está en la raíz.
- Productos, stock, precios y WhatsApp se editan en `products.js`.
- Fotos reales están en `/images`.
- Al entrar se ve directamente el catálogo.
- Filtros: Todos, Estampados, Colores y Premium.
- Cada producto abre una ficha con información completa, WhatsApp y compartir.

Para publicar en GitHub Pages, subí todos los archivos manteniendo esta estructura.
